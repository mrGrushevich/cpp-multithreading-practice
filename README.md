# Многопоточность и кроссплатформенность C++20

Учебные примеры и поиск строк с ERROR в текстовых журналах.

## Состав

- `01_threads` — четыре потока std::jthread.
- `02_race` — намеренная гонка данных (неопределённое поведение).
- `03_mutex_atomic` — сравнение mutex и atomic.
- `04_async` — async и future.
- `05_stop_token` — запрос остановки.
- `06_platform` — информация о платформе.
- `generate_logs` — 32 файла, 1 600 000 строк, 80 000 строк с ERROR.
- `logscan` — сравнение 1, 2, 4 и 8 потоков.

## Windows

Установить MSVC с поддержкой C++20. Открыть x64 Native Tools Command Prompt, перейти в папку проекта:

```bat
run_windows.cmd
```

## Linux / Kali

Нужен g++ с библиотекой C++20.

```bash
bash run_linux.sh
```

Журналы занимают около 300 МБ и создаются автоматически. Повторный запуск использует существующую папку logs. Файлы результатов в results заменяются при следующем запуске.

## CMake

```bash
cmake -S . -B cmake-build -DCMAKE_BUILD_TYPE=Release
cmake --build cmake-build --config Release
```

## Результаты проверки

| Потоков | Windows, мс | Kali Linux, примерно мс |
|---|---:|---:|
| 1 | 1863,675 | 1642 |
| 2 | 971,769 | 842 |
| 4 | 517,947 | 810 |
| 8 | 349,763 | 1791 |

Все режимы дали PASS. Лучшее ускорение: Windows — 5,33 раза (8 потоков), Kali — около 2,03 раза (4 потока). Условия запусков отличаются, это не прямое сравнение ОС. Семь замеров после прогрева, указана медиана. Kali округлён по скриншоту.

Проект восстановлен по фрагментам кода учебной презентации и проверен запуском. Пример 02_race специально содержит ошибку; даже правильный ответ не делает его безопасным. CMake-конфигурация подготовлена, основные проверки выполнялись скриптами.
